# Campus Hub · лабораторные работы 5–7

Учебное приложение на Expo SDK 57, React Native и TypeScript.

## Запуск

```sh
npm ci
npm start
```

Для браузера: `npm run web`. Для телефона откройте проект в совместимом Expo Go либо development build. Учебный вход принимает любой логин от 4 символов и пароль от 6 символов. Пароль не сохраняется и не отправляется на сервер. После полного перезапуска нужно войти снова, настройки сохраняются независимо от входа.

## Что реализовано

- ЛР 5: Login, Home, Services, Profile, Details; проверка полей; Stack и Bottom Tabs с иконками; передача ID и названия сервиса; возврат, выход, обработка неизвестного маршрута и неизвестного ID.
- ЛР 6: разделение экранов, компонентов, данных, типов, темы и состояния в `src/`; типизированные props; общие компоненты текста, кнопок и карточек; каталог на FlatList; настройки `.gitignore`.
- ЛР 7: SettingsContext, светлая и тёмная темы, три размера шрифта, AsyncStorage, восстановление после перезапуска. Дополнительно: сброс, системная тема при первом запуске, Splash во время загрузки, обработка ошибок хранилища.

Навигация использует Expo Router согласно AGENTS.md. Он объединяет стек и вкладки, а маршруты находятся в `src/app/`. Отдельный NavigationContainer не нужен. `App.tsx` подключает общие провайдеры, корневой layout — навигацию.

## Структура

```text
src/
  app/          маршруты, Stack и Tabs
  screens/      сценарии и композиция экранов
  components/   переиспользуемый интерфейс
  context/      настройки и учебная сессия
  data/         демонстрационные сервисы и курсы
  types/        модели, параметры маршрутов, настройки
  theme/        палитры, размеры и интервалы
  utils/        валидация входа и данных хранилища
```

Тема и масштаб текста применяются ко всем экранам, включая вход и детали. Настройки хранятся под ключом `@campus_hub_settings`. Быстрые изменения записываются последовательно. Неизвестные значения в сохранённых настройках заменяются значениями по умолчанию, ошибка JSON не блокирует запуск.
